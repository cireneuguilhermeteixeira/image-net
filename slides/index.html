04 · Live POC

Classify an image in Python.

from PIL import Image
import torch
from torchvision.models import (
  MobileNet_V3_Large_Weights,
  mobilenet_v3_large,
)

weights = MobileNet_V3_Large_Weights.DEFAULT
model = mobilenet_v3_large(weights=weights)
model.eval()

image = Image.open("my-image.jpg")
batch = weights.transforms()(image).unsqueeze(0)

with torch.inference_mode():
  probs = model(batch).softmax(dim=1)[0]

scores, ids = probs.topk(5)

05 · Takeaways

Useful baseline. Real limits.

1,000 labels

The model cannot predict concepts outside its fixed vocabulary.

Dataset bias

Web-sourced data carries representation and labeling choices.

Domain shift

Real-world data can be very different from the benchmark.

Remember: ImageNet is the dataset. MobileNet is the architecture. The weights are what the model learned.
