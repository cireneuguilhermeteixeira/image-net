04 · What production adds

A model is only one component.

Model

Classification, detection, landmarks, or segmentation—chosen for the actual question.

System

Camera, threading, smoothing, thresholds, alerts, storage, and observability.

Validation

Test with real users and conditions. Confidence is not guaranteed correctness.

Takeaway: ImageNet gives reusable visual knowledge; useful products combine it—or replace it—with task-specific models and engineering.
