01 · Origins · 2009

Why was ImageNet created?

The problem

Existing datasets were too small and narrow for recognizing objects in real-world variation.

The opportunity

The web had billions of images—but no clean, shared visual vocabulary at that scale.

WordNet: synonyms + meaning + hierarchy
Collect candidates from web search
Verify labels with human crowdsourcing

Introduced by Jia Deng and colleagues at Princeton at CVPR 2009. By 2014: 14.2M images across 21,841 concepts.

Source: ImageNet paper, CVPR 2009
02 · What changed

From dataset to deployable models.

2009

ImageNet

Large, diverse, human-verified image ontology.

2010

ILSVRC

1,000-class benchmark; teams engineer SIFT, color and texture features.

2012

AlexNet

Deep CNNs plus GPUs cut Top-5 error to 15.3%.

2019

MobileNetV3

Architecture search targets efficient inference on mobile CPUs.

The shift: describe features by hand → learn features from pixels → deploy efficient pretrained models.

Sources: ILSVRC · AlexNet · MobileNetV3

04 · Image classification

Classify one image.

weights = MobileNet_V3_Large_Weights.DEFAULT
model = mobilenet_v3_large(weights=weights)

image = Image.open(source)
batch = weights.transforms()(image)

probabilities = model(batch).softmax(1)
scores, ids = probabilities.topk(5)
